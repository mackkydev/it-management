# งานค้าง (คิวงานให้ Claude ทำต่ออัตโนมัติ)

งานตั้งเวลา "it-system-resume-pending-work" เปิดไฟล์นี้ทุก 1 ชั่วโมง (ขณะเปิดแอป Claude ไว้)
- ไม่มีรายการ `- [ ]` → จบทันที (ไม่อ่านไฟล์อื่น เพื่อประหยัด token)
- มี → ทำ **ทีละ 1 รายการ** จากบนลงล่าง แล้วอัปเดตสถานะในไฟล์นี้

รูปแบบ (เขียนรายละเอียดให้ครบในตัว เพราะรอบที่ตั้งเวลาไว้ไม่เห็นบทสนทนาเดิม):
- `- [ ] งาน — รายละเอียด / ไฟล์ที่เกี่ยวข้อง / เกณฑ์ว่าเสร็จ`
- `- [~] ...` = กำลังทำ (ใส่เวลาเริ่มท้ายบรรทัด) — รอบอื่นข้าม ยกเว้นค้างเกิน 3 ชั่วโมง (ถือว่ารอบนั้นหยุดกลางทาง ทำต่อได้)
- `- [x] ...` = เสร็จ (ใส่สรุปผลสั้นๆ + วันที่)
- `- [!] ...` = ทำไม่ได้/ต้องถามผู้ใช้ (ใส่เหตุผล) — รอบถัดไปข้าม
